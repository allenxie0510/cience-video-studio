# 初高中科学选题库

这是按知识前置条件划分的制作建议，不是某一版本教材的逐章对应。正式制作先确认学生已经学过哪些概念，再核对具体主题来源。初中通常先讲可观察变化与因果，高中可增加图像、变量关系、定量模型和模型边界。

| 学段 | 问题式选题 | 核心概念与动画重点 | 要避免的误导 |
|---|---|---|---|
| 初中 | 自行车换挡，为什么有时省力、有时跑得快？ | 链条带动不同齿数链轮；对照每踩一圈的车轮转数与力矩 | 链传动不是外齿轮直接啮合；别画错旋向，别混淆省力与省功 |
| 初中 | 一块钢会沉，钢造的船为什么能浮？ | 相同材料改变形状，展示排水体积与浮力平衡 | 不是只看材料密度；区分排水体积和船体总体积 |
| 初中 | 相机怎样把一棵树装进小小的传感器？ | 透镜、光线传播、物距与像距变化，逐步形成倒立实像 | 三条特殊光线只是作图工具，不是只有三条光线参与成像 |
| 初中 | 为什么关掉一盏灯，其他灯还能亮？ | 并联支路与开关位置；对比串联和并联 | 电流不被灯泡“吃掉”；把能量传递和电荷流动分开 |
| 初中 | 吸气时，是肺自己把空气吸进来的吗？ | 膈肌运动、胸腔容积与气压差的顺序变化 | 肺不是主动扩张的肌肉气泵；模型中省略的胸膜结构要标明 |
| 初中 | 反应冒出一串气泡，质量是不是变少了？ | 密闭/开放容器并排比较，追踪反应前后原子与气体去向 | 要区分体系边界；不能把逸散误讲成质量消失 |
| 高中 | 磁铁穿过线圈，为什么会产生电流？ | 磁通量变化、感应电动势、闭合回路中的电流与能量转换 | “有磁场就有电流”不成立；开路有电动势不等于有持续回路电流 |
| 高中 | 水波向前走，水也一直跟着往前跑吗？ | 给单个质点上色；比较局部振动与波形传播 | 基础线性波模型有边界，不能推广成所有真实水波绝无净输运 |
| 高中 | 卫星明明一直受重力，为什么不掉到地面？ | 相同高度不同初速度轨迹；自由落体与轨道比较 | 轨道上仍有重力；别用一个额外“离心力”抵消重力来解释惯性系轨道 |
| 高中 | 催化剂到底怎样让反应变快？ | 同温对比反应路径与能垒，连接到粒子有效反应事件 | 催化剂不改变反应的总能量差，也不改变固定条件下的平衡常数 |
| 高中 | 化学反应达到平衡，为什么还在反应？ | 两个方向同时发生，反应速率读数与宏观组成并列 | 动态平衡是正逆速率相等，不是浓度相等或微观停止 |
| 高中 | 神经信号为什么能沿着一根细胞传下去？ | 局部膜电位变化与相邻膜段的电压门控通道依次响应 | 不是同一批离子一路奔到神经末端；先讲模型再讲不应期 |

首批建议：初中“钢船为什么浮”容易做出直观对比；初中“自行车换挡”适合机械装置表现；高中“电磁感应”适合把不可见变量与可观察指针联动。每次只完成一个主要学习结果，再按需要做系列。
