# Anatomy 接入边界

上游：https://github.com/wheresryan22/anatomy
本次核对提交：`bc943e40c59998be5da61f9d39c6a983b1116099`（2026-10-15）。上游为 MIT；复制 kit 或改编源码时保留 LICENSE。

优先查找本机已安装的 Anatomy skill 或项目中的 `vendor/anatomy`；不存在时从上游取回上述固定提交。若运行原版示例，标注原作者，不作为本工作流的新创作成果。

上游是 Agent 指令与 SVG/等轴测工具包，含可选 WebGL、beta 3D、交互示例和几何检查；不是已封装的 TTS + MP4 产品，也不保证生成图的科学准确性。

按表现需求接入：

1. 找已安装的 `anatomy/SKILL.md`；没有则从上述仓库获取版本固定的源文件，记录实际提交。读取 `references/craft.md`、`references/kit.md` 和最接近的示例；调用工具前读取对应实现/说明。
2. `kit/iso-kit.mjs` 提供实体与 SVG；`lathe.mjs`、`tube.mjs` 做回转体、管线；`audit.mjs` 检查所记录几何。需要局部刚体转动时读 `references/3d.md` 与 `examples/turning-dial`；需要火焰、水面等效果时读 WebGL 文档。
3. 上游 beta 3D 主要是动态部件每帧重投影/重着色，背景仍可为静态图；不是任意相机路径的完整场景引擎。静态背景不能跟不上相机。用户需要透视变化、自由运镜、整体到微观的剖面时，可改用 Three.js 等真实 3D 场景，或有可用工具链时用 Blender；保留 Anatomy 的结构精度、克制材质、纯模型与接触检查，不强迫所有主题使用同一个 kit。上游偏爱固定图幅的制作取舍不覆盖本工作流的 3D 优先偏好。
4. 将原版 idle loop 和交互响应接到统一状态。提供纯函数 `stateAt(t)` 与 `setTime(t)`，不要录制一个自行漂移的动画循环。
5. 增设视频编排：标题、局部标注、旁白字幕、镜头与章节。视频解释可以使用外部引线/少量箭头；不必把原版“图内不放标签”变成阻碍教学的限制。
6. 检查几何和阅读顺序，再检查科学内容。用于完整精密 Anatomy 插图时遵循上游质检；草图/平面风格不虚称通过原版所有检查。

动画底层与视频编排分离：

```
可靠知识 → 纯模型 → 真实 3D / Anatomy 等轴测 / 按需二维辅助
旁白 → 实测音频 → timeline + shots → 模型时间 + 相机 + 剖切 + 高亮 + 布局 + 字幕
                                   ↓
                            HTML 预览 / 逐帧 MP4
```

不要为科普影片调用上游发布脚本；发布需要单独用户意图。不要强制所有选题堆够 40 个零件：这种细节标准属于原版精密插图路径，教学简化与其他风格按具体目标判断。
