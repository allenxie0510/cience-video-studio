# 自然中文旁白与时间轴

## 服务选择

先查当前项目已有 TTS 适配器和用户指定服务，仅检查必要配置是否存在，不打印密钥。已有火山/豆包、Azure、OpenAI 等时，按当前官方文档和实际账号能力选择中文音色；不要把文章提到某服务当作本机已配置。

本地 Voicebox 只在用户选择已有、获授权的声音档案时使用 `voicebox-voice-clone` 技能；服务可访问不等于已有适合的档案。用户未要求声音克隆时无需索取个人录音。

没有可用服务时保留 `voice.status=unconfigured`，完成脚本/字幕/画面。需要用户选择供应商或登录时，说明具体缺项；不把密钥贴进聊天、不凭空捏造 API、音色 ID、请求地址或配置成功。

## 统一接口

供应商适配器接收 `{id, spoken_text, voice, language, output_path}`，输出本地可播放音频路径和供应商元数据。适配器由当前供应商的已验证 API 实现，随附工具不内置未经测试的云 API 调用。

- `narration`：字幕里的标准书面内容。
- `spoken_text`：合成使用的发音形式，例如 TCP → T C P，SYN → 按目标音色实测的读法。
- `audio`：已生成音频的相对路径（相对 lesson.json）。
- `tail`：句后停顿，默认 0.25 秒。

先用一段包含中文、多音字、数字和英文术语的 8–15 秒样稿试听。禁止将没有听过的音频标记为“发音已核验”。正式片段尽量一到两句话，字幕可以在片段内继续拆分。

`pipeline.py prepare` 会解码音频为 48 kHz 单声道 PCM，按采样数计算时长并拼接句后静音；字幕在语音结束时关闭，尾停留不增加字幕时长。只有无音频的草稿允许使用 `draft_duration`，并须显式传 `--draft`。同一工程不允许部分有配音、部分无配音而悄悄静默补齐。

可选 BGM 必须有可用授权且不遮挡人声；不是默认必需项。机械音效按真实事件触发，示意模型没有真实碰撞时不添加误导性的碰撞声。整体响度与峰值在最终混音时统一，默认不逐句单独压响度以免音色忽大忽小。
