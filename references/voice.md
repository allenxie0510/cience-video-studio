# 自然中文旁白与时间轴

## 服务选择

先查当前项目已有 TTS 适配器和用户指定服务，仅检查必要配置是否存在，不打印密钥。已有火山/豆包、Azure、OpenAI 等时，按当前官方文档和实际账号能力选择中文音色；不要把文章提到某服务当作本机已配置。

本地 Voicebox 只在用户选择已有、获授权的声音档案时使用 `voicebox-voice-clone` 技能；服务可访问不等于已有适合的档案。用户未要求声音克隆时无需索取个人录音。

用户明确指定 Evan 时，读取该声音技能的 Evan 参考说明并复用语言匹配的现有档案；“好奇探索”用自然问句、短句、反应与停顿组织，沿用已确认的试听基准。先核对当前引擎是否实际支持情绪指令，不把请求字段存在当作控制生效。不要将 Evan、个人档案 ID 或参考录音写入公共默认配置；未指定 Evan 的项目不自动切换声音。

没有可用服务时保留 `voice.status=unconfigured`，完成脚本/字幕/画面。需要用户选择供应商或登录时，说明具体缺项；不把密钥贴进聊天、不凭空捏造 API、音色 ID、请求地址或配置成功。

## 统一接口

供应商适配器接收 `{id, spoken_text, voice, language, output_path}`，输出本地可播放音频路径和供应商元数据。适配器由当前供应商的已验证 API 实现，随附工具不内置未经测试的云 API 调用。

- `narration`：字幕里的标准书面内容。
- `spoken_text`：合成使用的发音形式，例如 TCP → T C P，SYN → 按目标音色实测的读法。
- `audio`：已生成音频的相对路径（相对 lesson.json）。
- `tail`：句后停顿，默认 0.25 秒。

先用一段包含中文、多音字、数字和英文术语的 8–15 秒样稿试听。禁止将没有听过的音频标记为“发音已核验”。正式片段尽量一到两句话，字幕可以在片段内继续拆分。

`pipeline.py prepare` 会解码音频为 48 kHz 单声道 PCM，按采样数计算时长并拼接句后静音；字幕在语音结束时关闭，尾停留不增加字幕时长。只有无音频的草稿允许使用 `draft_duration`，并须显式传 `--draft`。同一工程不允许部分有配音、部分无配音而悄悄静默补齐。

可选 BGM 必须有可用授权且不遮挡人声；不是默认必需项。机械音效按真实事件触发，示意模型没有真实碰撞时不添加误导性的碰撞声。整体响度与峰值在最终混音时统一，默认不逐句单独压响度以免音色忽大忽小。

## 单行口播字幕

本工作流默认优先单行显示；用户另有要求时按指定版式。少年实验系列默认无口播字幕底板，以描边、轻阴影与构图保证对比，具体见 [少儿美编](youth-art-direction.md#少儿节目文字与无底板字幕)。用连续短句替代同时出现的多行字幕，避免为塞下一整段话缩小字号或压扁文字。

- 先按语义写短句，常见起点为每条约 14–24 个汉字，但以目标画幅、字号和实际字体测量为准。专有名词、数字与单位不从中间切断。句子过长时在自然停顿处分成先后两条，不直接换行。
- 最稳妥的现有工具路径：每个短句对应一个 `lesson.json` 片段，单独生成配音并实测时长。相邻片段可共享同一 scene/shot，镜头进度按整个镜头所覆盖片段的起止时间计算，避免每条字幕让动画或相机重新开始。
- 一段连续配音需要多条字幕时，采用供应商时间戳或强制对齐，并核查起止。不要按字数均匀切时间后宣称已经精确同步。当前 `pipeline.py` 默认一片段一条 SRT；不内置词级对齐。
- 16:9 的 1280×720 输出可从约 28–32 px 字号、左右各 5% 安全边距开始。加载字体后使用实际字形包围盒校验；超宽先拆句/重排，保留标注与结论提示的独立区域。尺寸只是起点，仍要检查实际观看大小。
- HTML 烧录字幕与独立 SRT 使用同一条文字和同一段实测语音边界。检查每个 cue 只有一行文本、无显式换行、无裁切、无字号突变，并检查最宽字幕和切换帧。SRT 自身不能禁止所有外部播放器自动换行；交付时区分烧录版已验证与播放器排版能力。
- 对已做好的长字幕改为分句时，必要时重合成受影响音频，重建时间轴并重新导出；不能只在字幕里删掉旁白内容。简短停顿帮助理解，不把句间停顿堆成机械朗读。
