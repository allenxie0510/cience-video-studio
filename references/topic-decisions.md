# 少年系列选题：直观入口与深入挑战

用于12–15岁公众系列、周选题及超前学习者的拓展。以下是编辑和学习设计规则，不是标准化能力测评，也不把个别学习者的进度当作全体观众的起点。

## 把课程调研转成选题判断

- 年龄、概念深度、数学前置分别记录。读过某年级内容不能代替解释、预测、测量、迁移四方面的证据；数学未知时先用直观实验与可选数学拓展。
- 各国年级不直接等值；区分官方年级范围、阶段目标、选修模块和典型教材顺序。课程标准用于定位前置，主题科学事实另找一手来源。
- “大学概念”可以先建立有限直觉，完整推导仍需相应工具。高中也有量子现象，大学力学也研究熟悉运动；不用术语标签衡量挑战。
- 从物理主线中保留化学、生命和地球科学的迁移机会。系列可每4–6集穿插一题，按用户兴趣与实际效果调整，不机械配额。
- 课程版本、实施届别和考试变化属于易变信息；需要比较时重新核验，不把一次研究中的国家年级表固化为永久事实。

## 同一主题，两层交付

| 层次 | 学习结果 | 内容边界 |
|---|---|---|
| 公众短片 | 能用自己的话解释一个反直觉现象，并预测改一个条件后的结果 | 约90秒、60–120秒可调；生活对象、按题目安排预测与对照、一个核心解释；少量必要术语 |
| 可选挑战卡 | 用测量、图像或模型检验预测 | 一项任务通常20–40分钟，可分多次；列前置、材料、变量、记录表、解释与局限，不塞入短片 |

仅在用户需要进阶任务时增加上述深入挑战卡；普通视频请求不自动扩张交付。本少年系列后续新片默认随片交付的低负担探究任务卡另按 [少年观看与家长价值](family-value.md) 执行，可用纸笔预测或设计比较，不等于20–40分钟进阶任务。系列每周发布几条，不等于要求学习者在一周内完成全部深入任务。

挑战从浅到深可以是：预测方向 → 重复测量并画图 → 估算/拟合关系 → 比较模型与误差 → 完整推导。按证据选层，不按年龄贴标签。先给“你以为会怎样”的问题，再呈现关键证据；幽默来自反差、比赛、侦探任务或创作装置，避免虚构实验结果。

## 每题的最小决策卡

保存：稳定编号、现象式标题、观众、一个学习结果、公众先修、深入数学/实验前置、开场预测、可见证据、受控变量、挑战任务、来源与核验日期、模型边界、关键误区、制作可行性、是否复用/续篇及新增知识、推荐优先级与待验证项。

先排除不能核验因果、缺乏可辨认证据或无法在当前资源下准确呈现的题；其余比较学习增量、前置可达性、视觉表现、制作可行性。若打分，声明分项与权重是编辑判断，不伪装成流量数据。排期兼顾先修关系、题材变化和制作负担，不连续堆叠多个抽象高门槛题。

同题改标题或提高配色不算新选题。复用已有记录时保留旧版本、稳定编号及成片/封面关系；新题另建编号。延期的旧题保留在备库，并明确旧建议日期已被新排期替代；不标成已制作或已发布。

## 适合升级的桥梁与易错点

| 桥梁主题 | 公众入口／深入任务 | 不能省略的条件 |
|---|---|---|
| 储能与功率 | 弹跳玩具／测高度估能量、比较释放时间 | 瞬时输出增强不是能量凭空增加；纸玩具与机器人结构只是有限类比 |
| 共振与耦合 | 一只摆带动另一只／改摆长测周期和能量交换 | 共同支撑传力；有阻尼，不无限增幅 |
| 角动量 | 配重收拢转得更快／比较半径与角速度 | 外力矩小；动能增加可来自收拢机构做功 |
| 波叠加 | 两声源某处更安静／改探测位置或相位 | 局部抵消不等于全空间无声；仿真与实测分开 |
| 偏振 | 胶带夹在偏振片间显色／改角度比较强度 | 不产生新光；双折射不可简化成“胶带给光染色” |
| 混沌 | 双摆微小初值差／测分离时间并验证步长 | 确定性不等于长期可预测；数值误差不能当物理证据 |
| 熵与量子入口 | 小系统计数、光电阈值／概率或直线拟合 | 类比不等于完整理论；提前写明等可能、单光子等模型范围 |

## 制作与归档

现有视觉与声音规则继续生效：真实可辨器材、空间主题优先3D、合理遮挡、人物封面、单行无底板口播字幕与清晰对比。声音沿用用户当前明确选择，不因研究或难度升级擅换音色。

片前核验核心陈述与模型，片后检查旁白、画面、读数和字幕一致；未做真人专家审查不得标“专家审定”。未试拍、未实测和未收学生反馈分别标明。学生反馈至少分开问“想继续看吗”和“能解释/预测吗”，不要只看喜欢程度。

授权归档时，保存选题卡与来源、脚本、成片、横竖封面、标题简介和审校记录的关联。外部文档/表格的写入权限来自当次或既有用户授权，本参考本身不赋予发布或发消息权限。个人能力描述、账号标识、凭据和具体排期保存在项目资料，不写进公开skill。
