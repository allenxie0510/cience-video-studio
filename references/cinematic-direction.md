# 3D、镜头与认知版式

本工作流的用户偏好：能通过空间结构解释的内容，优先用 3D；在局部、关键动作和关系变化处调整镜头及信息组织。先让观众知道在哪里，再让观众看见发生了什么。

## 选择空间表达

- 机械、器官、细胞、材料层次、光路和有空间路径的物理过程：优先建立有厚度、前后关系与统一坐标的 3D 场景。先用简单几何保证结构，不以降低到平面图作为默认省时办法。
- 算式推导、状态机、数值曲线：二维可能更清楚，可作为主表达或叠在 3D 旁边。网络消息等抽象主题不强行做虚假的机械结构；用 3D 装置类比时明示映射。
- 真实 3D 是三维几何经相机投影形成画面：视角改变后，轮廓、视差、遮挡和受光相应变化。SVG 也能承载真实几何重投影，但仅给平面图加 CSS 透视、缩放和阴影不能宣称实现了 3D。
- 空间总览可用透视镜头，精确比较/剖面可用正交视图。选择由讲解任务决定，不把强透视畸变误当表现力。
- `brief.json` 记录 `render_mode`、引擎与选择理由。3D 依赖或性能受限时先减网格、粒子、材质与阴影复杂度；若仍只能降级，交付时明确实际维度和限制，不把平面版当作已经满足 3D 要求。

## 建模细节与镜头一起规划

本少年系列后续作品提高实体细节，不停留在概念积木层级；知识仍保持通俗，不因模型更细就增加第二个主知识点。简单几何可用于搭建结构小样，正式交付要把镜头会看见的对象做成可信实物。

- 先看可靠实物照片、结构资料或机构图，记录可辨轮廓、装配关系与材质。按最近机位确定细节：真实厚度、倒角、接缝、连接件、支撑、必要的孔口/网罩和内部层次；只做有依据、能帮助认物或看懂动作的细节，不虚构功能部件。
- 主体轮廓、关键装配与功能结构先正确，再补表面质感。软垫、金属、塑料、玻璃等以粗糙度、高光和透明关系区分，不只换颜色；少量使用纹理，避免过亮反光或细碎纹理遮住机制。
- 微距必须有值得看的结构：例如扬声器应有可辨振膜、悬边和支撑关系，而不是几个同心圆盘；剖面应能对应外部实物。不能把装饰细节当成科学结构已核实的证据。
- 在 `brief.json` 或镜头计划写出本集需要补足的关键细节、依据和可接受简化，按整体/最近机位分别检查。细节预算优先给解释焦点，背景从简；不以“示意”为由省略会影响装配与因果的结构。

## 按观众的问题选镜头与版式

| 观众此刻要理解什么 | 镜头 | 信息组织 |
|---|---|---|
| 这个东西在哪、整体是什么 | 透视全景/中景，必要时短弧线观察 | 主体占屏，少量部件名称；不常驻大段标题 |
| 里面有哪些关键结构 | 向目标推进，剖切/揭开外壳，落稳后讲解 | 清楚的切口、保留外轮廓参照，局部引线 |
| 一个动作究竟怎么发生 | 特写/微距，机位稳定，动作慢放 | 只保留相关部件；箭头和读数按事件出现 |
| 变化怎样传到下一处 | 沿路径跟拍，或稳机位让变化穿过画面 | 保留前后区域与方向，必要时加小型整体定位图 |
| 两种状态为什么不同 | 相同尺度/朝向的对照，或状态切换 | 分屏/画中画/前后叠对；不要把比较对象拍成不同倍率 |
| 结构动作如何对应曲线 | 局部动作与曲线同步，优先稳镜 | 主次分屏；同一模型时间驱动动作与曲线游标 |
| 局部原理怎样回到整体 | 拉回已建立的视角，重放完整因果链 | 保留对象身份，撤去细节标注；总结可直接落在物体上 |

这些是可选镜头语言，不是每片必做的七张页面。一个连续镜头可承载多句话；切镜依据认知任务和事件，不按固定秒数或每句旁白机械切换。关键动作发生时给足稳定观察时间，避免相机、部件、标签同时大幅移动。

## 后续作品的 3D 镜头多样性

在本系列已有整体→局部的基础上，下次分镜主动寻找更有表现力的三维观察方式，不让整片只在同一斜视角轻推拉。按当前问题选择短弧线环绕揭示前后层次、横移产生视差、俯视说明装配/路径、低角度突出动作、沿路径跟拍、外观匹配到剖面、整体与微距的尺度切换，或从局部拉回完整因果链。不是每片全部使用，也不为凑镜头频繁转场。

在 `shots.json` 说明所选变化揭示了什么、焦点是哪一件结构、何时落稳；判断全景到特写、外部到内部是否真的带来新信息。先建立方位，绕到另一侧或切换尺度后重新定位，避免左右与传播方向被误读。镜头进入可稍快，讲清机制与听声比较时停稳；不能用持续运动重新挤掉已确认自然的气口。

## 镜头连续性

- 镜头运动要回答一个问题：定位、揭示被挡结构、看清动作、追踪路径或建立比较。短弧线环绕、推进、横移与剖面切换按需使用，不为“有变化”持续旋转。
- 先标记目标部件，再推进或切特写；用形状、颜色、方向或定位小窗让观众认出仍是同一对象。跨到分子级示意时采用明确的尺度切换，不伪装成精确比例的连续穿越。
- 相机的 position、target、up 与 projection 是镜头数据；用平滑轨迹或姿态插值保持地平与目标稳定。进入目标时减速，讲到动作时停稳。
- 传播方向在相邻镜头中保持可读；换到反面可能让左右反转，要用方向标记或整体过渡重新定位。
- 用真实景别变化揭示新信息。对整幅平面图做 Ken Burns 缩放，不能替代 3D 局部结构；把关键对象从一张卡片移到下一张，也不是结构演示。
- 景深只作轻量辅助，通道、啮合处、接触边界和必要标签应清晰。过度虚化、抖动、闪光不承担“强调”的职责。

## 版式随教学任务变化

视频画布和网页控件分开。以全屏主体为基础，按需切到剖面、局部窗、对照或结构＋曲线；辅助信息退出后把空间还给主体。标题可在开场与章节入口短暂出现，不让固定大标题、边栏、底部四格贯穿全片。

屏幕字幕保持稳定安全区，口播默认优先单行；长句按 [单行字幕规则](voice.md#单行口播字幕) 顺序拆分，镜头可连续跨越多条字幕。世界标注跟随目标投影，遮挡时隐藏或调整引线。重点靠主体占屏大小、局部揭示、背景弱化和事件同步标注，避免同时塞入全套零件名、箭头、曲线与长字幕。背景弱化不改变真实物理层级。

## 标注、符号与字幕避让

- 把标题、实时读数、图表、部件标注、结论提示和旁白字幕分配到明确的屏幕区域。结论提示与旁白字幕留独立行距；部件标签不能挤入它们的安全区。边缘钳制也必须保留这些区域，不能把多个越界标签压到同一个底边。
- 字体加载后按实际文字包围盒（如 SVG `getBBox()`）检查大小和间距，不能只按字数估宽或只检查是否出屏。标签底板包含内边距，标签之间保留可读间隔；优先在部件侧面调整标签与引线，空间不足时简化次要标注或重排镜头。
- 实时读数与公式使用足够不透明的底板或独立留白，避免三维箭头、轨迹线透过文字。底板应覆盖整段读数及数字变化范围；不能遮住讲解所依赖的关键结构来换取文字清晰。
- 引线统一画在所有文字底板之下，避免后画的引线穿过先画的标签。图表游标按绘图区分段或裁切，不穿过公式标题和说明文字。
- 随 `setTime(t)` 确定性地计算投影与避让，不依赖上一帧布局。检查相机运动、最长字幕、正负号及读数位数变化、切镜前后；交互版还检查允许的视角范围。布局切换应稳定，避免标签来回跳位。
- 导出时可逐帧检查文字包围盒相交与出屏，并在失败时停止；自动检查后仍要看关键帧，确认箭头、实体、引线和文字的视觉关系。记录实际检查范围，不以“没有出屏”代表“没有重叠”。

## 镜头数据与统一时间轴

`shots.json` 与 `lesson.json` 分开：前者组织观察，后者承载旁白。每个镜头最少记录：`id`、`question`、`segment_ids`、`focus_ids`、`framing`、`camera`、`layout`、`reveal`、`transition`。模型实体 ID 与镜头焦点要能互相解析；制作时为引用的机位/布局定义实际参数。

镜头时段以片段 ID 加片段内进度或已确认的词级时间锚定。首次分镜可估时；配音完成后用 `timeline.json` 解析为真实秒数，不能把估时直接当最终时长。若相机尚未落稳而讲解已开始，重排动作/镜头节奏或加入明确的停留，不裁掉语音。

每次 `setTime(t)` 同时计算科学状态、相机姿态、剖面/爆炸位置、强调对象、布局、标签和字幕。相机不能靠上一次帧的增量更新；渲染与交互跳转到同一时刻须一致。改配音后保留镜头事件的先后关系，并重新计算边界。

## 神经信号案例：重制时的镜头设计

下表是下一次制作的镜头方案，不代表现有平面成片已经改成 3D。

| 讲解阶段 | 空间与镜头处理 | 认知重点 |
|---|---|---|
| 整体定位 | 立体神经元中景，小幅侧移看清细胞体与轴突；焦点沿轴突移动 | 同一个细胞，而非一串细胞 |
| 静息与内外分布 | 标记轴突一小段，推进到圆柱膜；纵向剖开一侧 | 膜内、膜外和膜本身是不同位置 |
| 钠内流、钾外流 | 从剖口切到单个通道的三维结构示意；停稳后展示跨膜方向 | 离子跨过当地的膜，不是沿轴突跑到末端 |
| 动作电位曲线 | 通道特写留主位，电位曲线作为小型辅助，游标与门控同源 | 通道状态与电位变化的因果对应 |
| 邻近膜接力 | 拉回多个相邻区域，沿轴突跟随兴奋；保留已恢复的后方 | 局部电流使下一段达阈值，再生新的动作电位 |
| 不应期 | 相机停稳，以前方/刚兴奋过的后方作同尺度比较 | 后方暂时难以再次兴奋；不把单向传播说成任何刺激都如此 |
| 髓鞘 | 显示髓鞘包裹的立体轴突，剖开一侧后跟踪内部局部电流；结处特写 | 覆盖段与郎飞结的区别；“跳跃”不是离子瞬移 |
| 回顾 | 拉回最初整体视角，沿真实结构重放一次传播 | 把局部机制放回完整路径 |

蛋白形状、离子数量、尺寸与教学慢放仍需标为示意；3D 材质不能暗示已取得分子结构或完成电生理仿真。

## 验收

- 先做代表性镜头小样：从整体定位到一个剖切/局部动作，验证体积、视差、遮挡和标注；不能只交一张带阴影的静帧证明 3D。
- 查看各镜头起点、中点、终点、切换前后与最差遮挡帧。确认焦点可见、结构无穿插、相机不切穿实体、文字不被裁掉。
- 比较关键镜头的占屏比例与信息组织。若除了标题、颜色和数字，主体景别/视角/观察方式几乎不变，重新检查分镜是否只是在翻页。
- 抽查无声画面：能否看出当前观察位置、重点对象和动作；再核对语音提到对象时它是否出现或完成定位。
- 关闭阴影再看接触/前后关系；沿相机运动路径复查透明排序与共面闪烁。继续遵守 [空间规则](spatial-depth.md)。
- `qa.json` 分别记录实际渲染维度、所检查镜头和未验证内容；格式校验通过不等于运镜或科学内容通过。

## 局部揭示与聆听镜头

讲到麦克风、接触点、通道或微小动作时，实际切到对应局部，不只给整件产品轻微推拉。先用整体视角定位，保留可识别的颜色/外轮廓，再按因果顺序揭开或切特写；局部标签逐项出现。为让出空间可撤去不相关部件，但不能让消失被误读为真实运动或机制。独立特写避免另一侧部件和头梁无意义地截断在画面边缘；退出后用拉回恢复整体关系。听声与同条件比较阶段稳定机位，把变化留给被测变量。

## 颜色与微小动作承担证据时

颜色实验、液滴、接触和开关等微小动作须在最终分辨率中可辨，不能只在模型坐标里成立。按实际镜头检查物体几何尺寸与对象缩放的乘积；整体定位后可切局部或适度放大示意，不能靠看不见的触发器直接跳到结果。放大尺寸和演示时间不能被读作实测量值。

让滴液、接触、混合和显色等因果事件共用一条事件进度；核看触发前、触面、结果出现后的实际编码帧，避免旁白说“滴入”而画面凭空换色。关键机制保持稳定可观察，再转场。

若色差就是比较证据，先做一组完整渲染色样：透明层排序、多层透射、曝光、色调映射和视频编码都可能改变颜色；不能用材质色号替代成片观察。比较对象保持同一照明、材质规则、背景和色彩管理，不为某杯单独调光来“做出”结论。光学近似和定性色板记录边界，不冒充光谱仿真或精确浓度/pH标定。
