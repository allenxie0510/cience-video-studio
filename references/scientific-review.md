# 科学审校：核对机制，而不只检查画面

正式科普视频必须有内容审查。用户要求严谨、专家级校验或指出科学问题时，加深审查；不要把资料核验、模型自检或多代理意见包装成真人专家审定，也不承诺绝对无误。

## 配音前

从本领域的教材/标准/原论文/官方技术资料建立 claim → source → 条件 → 镜头映射。为关键机制交叉核验；来源若来自同一底本的转载，不能算独立证据。记录实际访问范围，搜索摘录不冒充全文阅读。

以专业审稿人的问题检查脚本：

- 定义与参照是否明确？电位、浓度、速度、概率等量不能含混；“较多”不自动等于“浓度更高”。
- 原因、条件、结果是否倒置？必要条件有没有被说成充分条件？
- 典型值是否被当成普适常数？特定实验、物种、边界条件是否被遗漏？
- 教学类比和省略是否改变机制？例如转运泵不能画成普通开放孔道；相对不应期不能画成绝对不能再次兴奋。
- 是否有与常规情形不同、会改变结论的重要例外？在观众能理解的层次交代，不为了简洁传播错误规则。

将发现分为事实错误、易误解表达、可接受简化和未解决事项。先修正事实错误，再生成对应旁白。明确材料范围与学习目标，避免用长篇术语掩盖因果缺口。

## 动画与成片后

对事实模型做有意义的不变量检查：通道能否同时导通和失活、齿轮旋向是否满足啮合、数据包状态与字幕是否一致。验证画面、曲线、标签、旁白在同一时间表达同一事实。模拟中的恢复状态、实验条件切换和边界情况也要抽查。

画面正确并不证明知识正确；内部一致性测试不证明数值模型真实。分段插值、示意几何、缩放时间必须明确，不能伪装成真实测量或机制级数值仿真。

保存 `science-review.md` 或同等可读审校记录：范围、来源定位、发现、修改、最终状态、验证方式与限制。`sources.json` 同步更新。若未发生真人审查，记录 `human_expert_reviewed: false`；不得虚构专家姓名、资质或签字。若实际获得真人意见，保留审阅版本和结论，不能把旧签审套在新版本上。

## 用户指出错音

以用户提供的读音为准，给完整词组加注音并限定片段，避免改变其他词义。例如“膜内变得更正”里的“更”为 `geng4`，不是“更正错误”的 `geng1`。更新纠音词典，重合成受影响段，按实测音频重建字幕和动画时间轴，重新输出影片。

API 携带注音规则不等于已经听审正确；ASR 写对同音字也不证明声调正确。报告实际已做的确认，保留可单独试听的修订片段。
