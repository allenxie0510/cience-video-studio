# 可选择的六种风格

材质风格与空间维度分开选择。适合空间表达的选题优先 3D；同一风格可以有透视全景、正交剖面、局部微距和二维辅助图，不能因选了蓝图/杂志风就默认全片平面卡片。镜头规则见 [3D 与镜头编排](cinematic-direction.md)。

| ID / 名称 | 视觉与运动语言 | 适用内容 | 注意 |
|---|---|---|---|
| precision / 精密机械 | 深石墨背景、金属实体、四阶明暗、透视/等轴测、克制高亮、剖切与爆炸图 | 手表、发动机、设备结构 | 最接近 Anatomy；细节多时先遮蔽非重点 |
| museum / 白底展品 | 暖白展台、柔和投影、实物厚度、清晰分区、缓慢转台 | 消费电子、人体器官示意、产品原理 | 颜色之外要改变光照、留白与镜头距离 |
| blueprint / 工程蓝图 | 蓝底网格、投影轮廓、尺寸/路径和数值读数、步骤追踪 | 工程关系、电路、网络协议 | 网格是视觉风格；未核对的数字不可伪装工程参数 |
| paper / 纸艺拆解 | 暖纸背景、叠纸轮廓、剪切边与层间阴影、分层滑入 | 入门科普、生活原理、儿童友好解释 | 形变不能掩盖真实接触关系；减少装饰 |
| chalk / 黑板推演 | 深绿底、粉笔线与局部手绘标记、依次显现、算式积累 | 数学、算法、推理过程 | 要有实际推演步骤，不能只是黑底字幕 |
| editorial / 杂志信息图 | 米白底、粗轮廓、高对比块面、大数字、分屏比较 | AI/计算机通识、对比解释、短视频 | 配色保持功能一致；对比时可分屏；因果动作中保持观察连续 |

统一的语义层：`subject` 当前讲解对象、`context` 背景结构、`signal` 能量/数据、`caution` 误区。主题切换只改表现，不能把同一个零件改成另一种含义。

所有风格共用 [空间层级与阴影规则](spatial-depth.md)。纸艺只对真实分层的结构做叠纸错位，不能把共面啮合的两个齿轮画成前后两层；当前高亮不能改变物理深度。无法可靠呈现时，弱化或取消阴影，优先保证空间关系准确。

预览用同一段齿轮模型比较六种图形处理：金属色调、白底柔影、网格与节圆、纸面质感、粉笔纹理、平面粗线。两个齿轮保持共面，使用排除前表面的共同淡投影，不用错位副本伪造厚度。它只代表平面风格方向，不代表 3D 镜头能力或最终质量；正式空间视频应先做有真实视差、遮挡与局部特写的 3D 小样。

风格与结构是两个维度：先决定真实机械、流程推演或物理比喻，再决定画风。TCP 不必发明齿轮协议；可用双端通信台表达消息往返，并保留真实状态和序列号逻辑。
